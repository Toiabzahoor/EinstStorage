# Einst Storage

Hello guys, I hope you are all well. This is my project, and I named it **Einst Storage**. I made this for **Crescent (Hack Club)** when I saw that one of their programs lets you encode files in a format that wasn't really designed for encoding files. So I decided: why shouldn't I encode a file in a MIDI format so that we can decode it, or play it to see what the file actually sounds like?

---

## How It Works

How this project works is really simple:

* You take a file, put it in, and encode it into MIDI, and in return you get a MIDI file.
* We also have a decoder that can decode the MIDI back into a file.
* We also have a MIDI player, which, of course, plays the music.

---

## Technical Notes & Aesthetic

* **Shorter Tracks:** If you think about it, most tracks are really long, so I had to do a bit of work in order to make the tracks a bit shorter by using some symphonic knowledge.
* **Theme:** In this project, I also used a **Frutiger Eco** theme. Why? Because I really like the aesthetic, and I would really like to make everything Frutiger Eco.
